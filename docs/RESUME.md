# 简历项目素材

依据当前代码快照及设计报告整理。职责尚未由项目成员逐项确认，个人简历仅选用本人实际承担的工作，不把团队全部成果默认归为个人。

## 项目名称与技术栈

**基于 STM32N6 的工业视觉缺陷检测与剔除系统**

STM32N6 / Neural-ART NPU / ThreadX / ST Edge AI / YOLO11n / INT8 输入输出处理 / I²C / PCA9685 / LCD

## 可选描述

- 面向瓶盖表面瑕疵检测，基于 STM32N6 和 ThreadX 组织图像采集、NPU 推理、LCD 显示及舵机剔除控制，通过双缓冲、信号量和互斥锁解耦图像处理与结果显示。
- 实现 320×192 图像到 320×320 的居中填充及 INT8 输入转换，调用 LL_ATON 运行时执行推理，完成输出反量化、置信度筛选与同类别 NMS，支持两类缺陷检测和 LCD 叠框。
- 采用剔除事件队列与动作队列，分离调度线程和舵机执行线程，通过软件 I²C 控制 PCA9685 产生 PWM；实现固定触发延时、重复事件过滤及推出/复位分段动作，避免在推理线程中同步等待舵机。
- 若本人承担算法训练，可补充：完成 YOLO11n 训练、验证与 ONNX 导出；报告记录在 96 张图像、96 个实例的 PC 验证集上 mAP@50 为 96.95%、Recall 为 97.1%。本次未独立复现实验。

## 不宜直接写入的结论

- “STM32N6 单张推理 18.2 ms”：该耗时来自 PC 验证日志。
- “准确率 96.95%”：该值为 mAP@50。
- “全网络 INT8、完全由 NPU 执行”：仅能从当前源码确认 INT8 输入输出处理。
- “完整工程开箱可编译”：本包是重点代码快照，缺少工程与依赖。
- “工业产线稳定运行、剔除成功率达到某值”：没有相应实测记录。
- “完整故障状态机与自动带速补偿”：当前快照使用固定延时与工作线程，缺少对应实现证据。
